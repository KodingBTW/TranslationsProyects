Traducido por koda 2026

## 1. INSTRUCCIONES

### Paso 1:

Copiar la ROM a la carpeta raíz

Este parche debe ser aplicado a la versión americana con cabecera.

La ROM es:

```
Database match: Uninvited (USA)
Database: No-Intro: Nintendo Entertainment System (v. 20210216-231042)
File SHA-1: 38A0F366DF579C86679F54FE8803FE9D81223257
File CRC32: 8579FA86
ROM SHA-1: 6802A12A7A33D09C6DA6185A59DB69FDD5A9A6D9
ROM CRC32: 9BAC73EF
```

### Paso 2:
Renombrar a "Uninvited (U) [!].nes"

### Paso 3:
Crear el parche dando click a "build.bat"

### Paso 4:
Esperar a que termine, esto generará "Uninvited (ESP).nes"

```
Database: No-Intro: Nintendo Entertainment System (v. 20210216-231042)
File SHA-1: 1F8B70E6A197EFC578FCE34E26F183B8D568C138
File CRC32: D179A67F
ROM SHA-1: 0300C019177494E664EE1493E5134748B97A7338
ROM CRC32: CFAC2F16
```

Además se crearán 2 parches "Uninvited (ESP).bps" y
"Uninvited (ESP).ips" 

### Paso 5:
Disfrutar del parche.
