Aterix de SMS
Traducido por koda 2026

## 1. INSTRUCCIONES

### Paso 1:
Copiar la ROM a la carpeta raíz

Este parche debe ser aplicado a la versión americana sin cabecera.

La ROM es:

```
Database match: Asterix (Europe, Brazil) (En,Fr) (Rev 1)
Database: No-Intro: Master System (v. 20210216-223458)
File/ROM SHA-1: AE56C708BC197F462B68C3E5FF9F0379D841C8B0
File/ROM CRC32: 8C9D5BE8
```

### Paso 2:
Renombrar a "Asterix (Europe) (En,Fr) (Rev 1).sms"

### Paso 3:
Contruir el parche dando click a "build.bat"

### Paso 4:
Esperar a que termine, esto generará "Asterix (Esp,Cat).sms"

```
Database match: Asterix (Europe, Brazil) (En,Fr) (Rev 1)
Database: No-Intro: Master System (v. 20210216-223458)
File/ROM SHA-1: 3D2394672FF442750365A7CF63AA8257E435921D
File/ROM CRC32: C12DA33D
```

Además se crearán 2 parches "Asterix (Esp,Cat).bps" y
"Asterix (Esp,Cat).ips" 

### Paso 5:
Disfrutar del parche.

## 4. ACERCA DE LA TRADUCCION

Al iniciar con la traducción, no se tenia contemplado crear una versión al catalán de la 
misma, simplemente se dejaría la parte francesa como idioma secundario. Sin embargo, gracias
a los colegas traductores se me ha dado la idea de usar la parte francesa para crear una
catalana. Para ello he tenido que pedir ayuda, puesto que su servidor no maneja el catalán.
Fue así que Noishe, un romhacker conocido en la scene, se ha ofrecido a ayudarme a traducir
el texto, al cual mando un afectuoso agradecimiento.
